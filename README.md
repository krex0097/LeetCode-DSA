# leetcode-dsa

My personal repository for tracking LeetCode solutions and mastering Data Structures & Algorithms. All solutions are automatically synced from LeetCode using the LeetSync extension.

## 🛠️ Environment & Language
* **Language:** C++ (C++17 / C++20)
* **Standard Library:** Heavy use of `<vector>`, `<unordered_map>`, `<queue>`, `<stack>`, and `<algorithm>` for optimal performance.

## 📚 Topic Breakdown

### Core Data Structures
* **Arrays & Hashing** — Two Pointers, Sliding Window, Prefix Sum (`std::vector`)
* **Linked Lists** — Singly, Doubly, Fast & Slow Pointers
* **Stacks & Queues** — Monotonic Stack, Deque (`std::stack`, `std::queue`, `std::deque`)
* **Trees & Graphs** — BST, DFS, BFS, Matrix traversal, Disjoint Set (DSU)
* **Heaps** — Priority Queues (`std::priority_queue` Min/Max Heap patterns)

### Advanced Algorithms
* **Binary Search** — Search space reduction, `std::lower_bound`, `std::upper_bound`
* **Sorting** — Custom comparators with `std::sort`
* **Dynamic Programming** — 1D/2D DP, Memoization, Tabulation space-optimization
* **Greedy & Backtracking** — Permutations, Combinations, State-space pruning
* **Bit Manipulation** — Bitwise operations, Masking (`__builtin_popcount`)

## ⚙️ Automation Setup
This repository updates automatically every time a solution hits **Accepted** on LeetCode.
